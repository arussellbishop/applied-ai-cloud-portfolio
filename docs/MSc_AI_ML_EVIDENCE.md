# MSc AI/ML evidence

## What is currently publishable

The repository contains bounded historical research evidence for an interpretable Hidden Markov Model study of gold and silver market states. The accessible record describes 857 weekly observations, train-only preprocessing, prefix-only inference, trend/momentum/volatility features, reconciliation work and explicit negative findings. The Finance Lab records rejection registers, Monte Carlo diagnostics, multiple-testing controls and an untouched holdout.

The defensible transferable skills are methodological discipline, feature lineage, temporal evaluation design, reproducibility review and refusal to turn incomplete provenance into an outperformance claim.

## Evidence boundary

This repository does not contain the formal MSc award certificate, dissertation manuscript, supervisor confirmation, transcript, authoritative module list or assessed module project artefacts. It also does not contain the licensed/raw inputs and complete regeneration code required for a fresh source-only replay. The source-input-only rebuild was recorded as invalid.

Therefore the portfolio presents the research method as validated historical evidence, not as a claim of a completed degree, a reproducible investment system or trading performance.
