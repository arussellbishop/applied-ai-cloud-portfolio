# Supplier and Supply-Chain Assessment

Assess each model, embedding provider, software dependency, corpus source, hosting provider and support provider.

Record ownership, processing location, data use, retention, security measures, incident duties, change notice, audit rights, licence, provenance, vulnerability handling, subcontractors, exit plan and business continuity.

No supplier statement is accepted without evidence. Public model availability does not prove suitability, licence rights, security or regulatory compliance.
