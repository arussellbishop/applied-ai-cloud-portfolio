## Security and privacy scan scope

The repository scanner checks text and forbidden file/artifact patterns for credentials, private keys, real environment files, account identifiers, endpoint addresses, personal filesystem paths, private repository links, datasets and debug/archive artifacts. It reports categories and locations, never suspected secret values. Manual review covers newly published evidence fields, authorship and historical provenance. Narrow existing exceptions cover local loopback/wildcard listener literals and fictional Terraform CIDRs; these are not deployment endpoints. Generic operating-system paths in executable deployment code are implementation details, not private home directories. Scans provide targeted evidence, not a guarantee against every possible undiscovered secret or a formal penetration test.
