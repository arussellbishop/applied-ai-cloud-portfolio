# RAG and AI threat model

Assets include personal data, prompts, retrieved context, model weights, outputs, logs and governance records. Threats include direct/indirect prompt injection, retrieval leakage, poisoned documents, unauthorised access, insecure dependencies, model change, data poisoning and denial of service. Controls include least privilege, local-only default binding, document sanitisation, untrusted-data treatment, allow-listed sources, provenance/hashes, output validation, human approval, security testing, incident response and controlled change.

No control is treated as effective merely because it is documented: tests and owner evidence are required.
