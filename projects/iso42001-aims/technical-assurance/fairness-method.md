# Fairness assessment

This synthetic assessment reports selection rate, true-positive rate and false-positive rate by synthetic gender and age groups. Differences are signals for investigation, not automatic proof of unlawful discrimination. A competent reviewer must select context-appropriate metrics, examine causal factors, consult affected stakeholders and decide mitigations.

The test is intentionally limited: no protected characteristic is used as a model feature, but synthetic group labels are retained for post-hoc testing.
